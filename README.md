Universidad de La Guajira

Ecuaciones Diferenciales - Unidad III

## Descripción

Este proyecto implementa modelos matemáticos usando ecuaciones diferenciales de primer orden, aplicados a diferentes fenómenos reales.

Temas incluidos

Ley de Enfriamiento de Newton

Crecimiento y Decaimiento Exponencial

Mezclas y Dilución

## Requisitos

Instalar las siguientes librerías antes de ejecutar:

pip install numpy matplotlib scipy
## Cómo ejecutar

Ubícate en la carpeta del proyecto y ejecuta:

python modelos_ED_primer_orden.py
## Estructura del proyecto

modelos_ED_primer_orden.py
